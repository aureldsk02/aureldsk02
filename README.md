### My Current Projects

**Tilia** is my main project right now. It's an application that allows anyone—artisans, small merchants, entrepreneurs—to easily create their own online store without needing technical skills. The idea came to me when I saw how many people around me had great products to sell but struggled with the technical side of e-commerce. I want to make it accessible to everyone.

At the same time, I'm working on:
- **Cybersecurity tools**: automation scripts for pentesting, small programs to analyze vulnerabilities, stuff that helps me learn by doing
- **DevOps automation**: setting up CI/CD pipelines on AWS and other cloud platforms, infrastructure as code with Terraform, monitoring and logging
- **Blockchain projects**: learning by developing small smart contracts and exploring different decentralized architectures
- **Cybersecurity research**: participating in CTFs, writeups, exploring new exploitation and defense techniques

My approach is always to learn by doing. I prefer diving into a concrete project rather than just reading theory.
